# Study Genie


#### Video Demo: https://youtu.be/2NEDosZaaRM?si=ZXE-anMys97FxuUo


#### Description: 

The project I did is developing an iOS application called Study Genie, which students can utilize in order to transform their notes, pdf files, and scanned documents into flashcards and quizzes. The rationale for this project is based on personal experience. I personally need to take a lot of notes from class, from assigned reading, and from other various documents given out in class. However, spending time creating these flashcards takes a lot of time. As a result, I have avoided using flashcards in class when in reality they are one of the most effective ways of studying a subject.

The ultimate objective of Study Genie is to assist students in learning active recall, which involves self-testing rather than studying by re-reading written notes. Studies have indicated that active recall is an effective way of learning information because it can help students recall information better compared to other methods. The challenge with active recall is that students find it tedious because it takes time to make flashcards. Study Genie assists students in creating flashcards based on a piece of text they provide.

One of the most important aspects of Study Genie is its capability to handle different formats of files. The app possesses the capability to upload text files and PDF files. Moreover, if the uploaded PDF contains selectable text, it can immediately read it. However, in most school records, scanned images of texts are used, and not actual texts. To deal with this, I incorporated OCR, or Optical Character Recognition, into this application. With this capability, it can read texts in images by analyzing them page by page based on their visual appearance. Of course, this is among the most challenging parts of this project since scanned images can be blurry and of poor quality. To address this problem, it enhances each page of each image by adjusting contrast and making it sharper before it can read it.

Study Genie offers control over the number of pages scanned using OCR technology. The need for this control arises because scanning a large number of pages may slow down an application such as Study Genie. Therefore, controlling the scanning of a large number of pages prevents Study Genie from freezing or slowing down. As a matter of fact, if a large number of pages scanned using OCR technology do not work well, a person can always copy and paste their notes into Study Genie.

Once this text is obtained, Study Genie begins creating flashcards. Rather than creating flashcards with random or poor-quality questions, this application begins searching for a pattern in the text. In other words, if a text contains definition-format information, such as "Term: definition" or "Term – definition," this application converts this information into a "Define" flashcard. Furthermore, this application searches for question marks in texts and converts them into "Question/Answer" flashcards. Additionally, this application searches for sentences in texts with relationship information, such as "X causes Y" or "X leads to Y," and converts them into "Fact" questions.

The other problem I had to address in this project is removing unnecessary characters from the text. While using OCR technology, sometimes these characters appear in excess in the scanned text. They can be page numbers or random letters such as "B" or "C." They would not make very good flashcards if they were left in their original state. To remove them, I used additional parameters to eliminate unnecessary text.

On a technical front, Study Genie is an application developed using SwiftUI, which is a future-facing application framework developed by Apple. I have used various files in this project such as models for flashcard storage, views for GUI, and other utility functions such as image processing using OCR algorithms. Additionally, this project incorporates state management solutions such that flashcards automatically appear in the study and quiz views when they are produced. Working on this project was very educational for me. I learned just how hard it can be to make a real-world dataset into a clean and working format. I learned that small decisions, such as making text readable and providing good instruction, can make a large impact when working with a project. Bug fixing, which affected the project when it would not build or crash when small issues were present, improved my patience and attention to detail. Overall, Study Genie is a project which brings technology and education together in a way which matters. The project tackles a problem which students have, such as myself before, and promotes good study practices. Ways which I would want to improve this project if I were to carry it forward would include progress tracking, flashcard spacing, and adjusting quiz difficulty based on performance. Through completing Study Genie, I have learned how coding can be used for education, making learning simpler, and this project inspired me to carry out more projects such as this in the future.
